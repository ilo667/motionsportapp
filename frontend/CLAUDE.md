# Motion Gym — Frontend

Next.js 16 App Router PWA. Backend API runs on port 3001 (proxied via `/api` rewrites in `next.config.ts`).

Key files:
- `app/` — pages: `/` (schedule + unauthenticated landing), `/login`, `/register`, `/forgot`, `/admin`, `/admin/login`, `/admin/calendar` (calendar; the add / training modals in `AddSlotModal.tsx` / `EditSlotModal.tsx` next to the page), `/admin/clients` (short list: name → client page, club card badge, trainings left, note, trainer, cancellations count; cash requests on top), `/admin/clients/[id]` (client page: trainer, note, club card and trainings with «Активувати», visits, cancellations, purchases; shared pieces in `components/admin/ClientParts.tsx`), `/admin/schedule` («Розклад групових»: weekdays as rows, times as chips with «+ час», «Запис відкривається о», «Автоматично додавати на 3 тижні наперед», «Зберегти»), `/admin/history` (past days as an accordion, attendance editable), `/admin/stats` («Статистика»: revenue as one card by default: «Весь час» / «Місяць» with ‹ › through every month from the first paid one; «Графік» switches to a bar per month for the last 12 (zero months included), a tap on a bar picks the month; the picked month carries over; by type — club cards / персональні / спліт / групові; busiest days and average per weekday, by people ✓), `/admin/prices` (shared price list: tap a price to change it, confirm «для всіх тренерів», change history), `/admin/trainers` («Тренери»; sections in `InviteSection.tsx`, `DisableDialog.tsx`, `PasswordSection.tsx` next to the page: «Створити посилання» for a new trainer, shown once, waiting invites with «Відкликати», all trainers with «запросив(ла)» and «вимкнено», «Вимкнути» (not on yourself or the first trainer; a dialog picks whom the clients go to), «Змінити пароль»), `/admin/join?t=` (invite sign-up, `components/admin/TrainerJoinForm.tsx`; a dead link shows «Посилання недійсне»), `/purchases` («Мій абонемент»: club card, packages, pending purchase; `?type=персональні|спліт` opens the purchase flow for that type), `/prices` (price list for a signed-in client, from «Мій абонемент»; server component per request, passes the `session` cookie to the backend itself; same `PriceList` as `/admin/prices`), `/payment/return`, `not-found.tsx` (404 for any unknown URL)
- `components/` — `Header`, `MotionGymLogo`, `PageLayout`, `LoginForm` (member/admin login), `PaymentResult` (`/payment/return` status), `SwRegister`, `OfflineBanner` (sticky "Немає інтернету" strip after 5 s offline, in `app/layout.tsx`), `SlotCard` (group slot; «Запис відкриється о HH:MM» from `bookingOpenAt` (`lib/kyivTime.ts`), «Запис закрито» once `slot.started`; without a group pass «Записатись» opens `GroupPassModal`: single visit / pass by LiqPay, or cash to the trainer; on the member's own booking «+ Привести гостя» → name → «Додати гостя», then «Гість: Ім'я» with «Прибрати»; guests appear in the trainer's lists indented right under the member, with a «гість» badge and their own ✓/✗, `api.updateParticipantAttendance` picks the route), `AssignedSlotCard` (personal / split: booked by the trainer; «Залишилось N тренувань» or «Оплатити» → `/purchases`), `MyPurchasesPage` + `PurchaseFlow` (modes: service → club card if none → LiqPay or cash; a club card alone; a group pass), card / package states (waiting for activation, active until), `GymLoader`, `PushSubscribeButton` (trainer page), `admin/AdminMenu` (burger in the header of every trainer page: Панель тренера / Клієнти / Календар / Розклад групових / Історія / Статистика / Ціни / Тренери / Вийти, same on phone and desktop), `admin/SlotCard`, `admin/AttendanceButton` (— → ✓ → ✗ toggle, today page and history), `admin/CancellationList` (who cancelled/moved and why: today page, calendar modal, client history), `admin/StrayPayments` (top of «Клієнти», «Гроші без покупки»: paid after the purchase ended, payment number for a refund, «Розібрано»), `admin/CashRequests` (top of «Клієнти», «Підтвердьте оплату»: one big «Отримано N ₴», «Відхилити» as a small link), `admin/CancelRefunds` (top of «Клієнти», «Повернути гроші»: half of a single training after a late cancellation, «Повернено N ₴»), `admin/FreezeRequests` (top of «Клієнти», «Заморозка»: freeze / unfreeze requests; «Заморозити» asks once more, since the client's trainings in those days are cancelled), `FreezeBlock` (on «Мій абонемент»: «Заморозити абонемент» with the rules, then the request / «Заморожено до DD.MM» / «Розморозити раніше»; the «Купити» block hides while a freeze is open), `admin/MemberPurchases` (under a client: club cards with a state badge and «Активувати з сьогодні», «Послуги тренера й абонементи», purchase history, «+ Додати клубну карту з рецепції» → «Додати» / «Додати й активувати з сьогодні»). In the UI it is always «клубна карта», never just «карта», and no «пакет»
- `lib/api.ts` — typed fetch wrapper for all backend calls; its types live in `lib/apiTypes.ts` and are re-exported, so import them from `@/lib/api`
- `lib/trainingTypes.ts` — `TYPE_COLORS` for training types (calendar, history)
- `lib/liqpay.ts` — `submitLiqPay(checkout)` (form POST to LiqPay); prices come from the API, nothing hard-coded

Page container (`max-w-xl`, `px-5`) is defined once in `app/layout.tsx`. `PageLayout variant="top"` adds the bottom padding (`3rem` + the iPhone safe area); centered pages have none. Pages return content directly without wrapper `<main>` tags.

Auth state: `mg_authed` key in `localStorage` — set on login, cleared on logout or 401. Used on `/` to skip the API call for unauthenticated users (avoids 401 in console).
